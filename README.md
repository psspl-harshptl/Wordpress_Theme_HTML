# SharePoint Experts - HTML Theme

This repository contains a static HTML website template designed for a SharePoint consulting, development, and migration business.

## Project Structure

The project directory is organized as follows:

-   **`pages/`**: Contains all the HTML pages for the website.
-   **`assets/`**: Contains the static assets including styles, scripts, and images.
    -   `css/`: Stylesheets (Custom styles and Swiper.js styles).
    -   `js/`: JavaScript files.
    -   `images/`: Project images and icons.

## Getting Started

To view the website:

1.  Navigate to the `pages` directory.
2.  Open `index.html` in your web browser.

You can navigate to other pages through the navigation menu or by opening the respective HTML files in the `pages` directory.
